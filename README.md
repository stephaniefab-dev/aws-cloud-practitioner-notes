# AWS Cloud Practitioner — Notas de estudio

Repositorio donde voy documentando mis notas mientras estudio para la
certificación AWS Cloud Practitioner. Es un espacio de aprendizaje en
proceso, no una guía oficial ni un recurso completo — simplemente voy
organizando lo que aprendo a medida que avanzo.

Las notas siguen la ruta "AWS Cloud Practitioner Essentials (Español LATAM)"
de AWS Skill Builder.

## 📂 Contenido

- `01-introduccion-a-la-nube/` — Conceptos básicos de la nube, regiones y
  zonas de disponibilidad, modelo de responsabilidad compartida
- `02-computacion-en-la-nube/` — Amazon EC2, escalado, balanceo de carga,
  mensajería y colas (SQS, SNS, EventBridge)
- `03-exploracion-servicios-computacion/` — Computación sin servidor, AWS
  Lambda, contenedores y orquestación (ECS, EKS, Fargate), otros servicios
  de cómputo
- `04-hacia-la-globalizacion/` — En progreso 🔄

## 🎯 Objetivo

Prepararme para la certificación AWS Cloud Practitioner y tener un
registro propio de lo aprendido en el camino.
